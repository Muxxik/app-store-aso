## 2026-08-25

Пополнение канона из второго живого цикла (приложение no-contact-ниши, 14 локалей, релиз 1.1 + фикс 1.1.1).

**Метрики**
- Индекс Search Ads: Apple расширила «пол» — всё ниже ~44–45 показывается как 5. Двойное значение в ASO Mobile («5 | 39») — текущий индекс | значение до изменения шкалы; для нишевых ключей читать второе.

**Методичка**
- Новая ловушка шага 5: после релиза проверять `live` по каждой стране — Name/Subtitle новых локалей могут молча не сохраниться в ASC (реальный случай: 5 локалей уехали с одними кейвордами при старом английском имени).
- Модель индексации: пунктуация в Name не влияет на токены; коллизию имён в ASC лечит замена знака.
- Решение об открытии локали: находки не переносятся между рынками, даже родственными (замеры: английский термин против местного — FR ~1:1, DE 16:1, IT 103:1; живые слова Испании и Мексики расходятся).
- Новый антипаттерн: брать слово по индексу, не проверив интент (separazione = развод, superar в BR = курсы, Herz* = пульсометры).

## 2026-08-24

Обкатка на реальном цикле (2d-игра, 9 локалей) — всё ниже родилось из настоящих граблей этой сессии.

**Скрипты**
- `store-query.sh suggest` принимает коды стран (`us`, `jp`, …) и сам мапит их в ID сторов; незнакомый код — внятная ошибка вместо пустого ответа, маскирующегося под рейт-лимит; непроверенные ID помечаются предупреждением.
- Новое: `analyze.py event` — детектор платформенных событий: находит дату, когда показы ступенькой выросли сразу в нескольких несвязанных странах без роста загрузок, и предлагает чистый период для замера.
- Новое: `validate-fields.py` — валидатор пакета метаданных перед отправкой: лимиты 30/30/100, недобор keywords (<90), синтаксис, дубли внутри локали и между локалями одной страны (по карте индексации), распознавание локалей-контейнеров, фильтрация брендовых токенов.
- `store-query.sh live` достаёт сабтайтл из HTML витрины (обе вёрстки Apple); жанр вместо сабтайтла = локаль в стране не заполнена.

**Методичка**
- «Порядок работы» переписан в чек-лист: у каждого шага явная ловушка, без которой шаг не закрыт.
- Новое правило индексации: региональные варианты написания (defence/defense) — разные токены; американская форма в en-US, британская в en-GB.
- Новое правило сборки: keywords добивать до ~100 символов в каждой локали.
- Япония (143462) переведена в проверенные ID сторов.
