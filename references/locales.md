# Карта локалей и ID сторов

## Какие локали индексируются в какой стране

Источник — таблица AppTweak + официальный справочник App Store Connect (`developer.apple.com/help/app-store-connect/reference/app-store-localizations`). Проверяй актуальность: Apple меняет её без объявления (в декабре 2018 en-GB/en-AU перестали индексироваться глобально).

| Страна | Основная | Дополнительно индексируются |
| --- | --- | --- |
| США | en-US | Arabic, Chinese (Simpl.), Chinese (Trad.), French, Korean, Portuguese (BR), Russian, Spanish (MX), Vietnamese |
| Великобритания | en-GB | — |
| Австралия, Новая Зеландия | en-AU | en-GB |
| Канада | en-CA | fr-CA |
| Франция | fr-FR | en-GB |
| Германия, Австрия | de-DE | en-GB |
| Швейцария | de-DE | en-GB, fr-FR, it-IT |
| Италия | it-IT | en-GB |
| Испания | es-ES | en-GB |
| Мексика и испаноязычная Латинская Америка | es-MX | en-GB |
| Бразилия | pt-BR | en-GB |
| Португалия | pt-PT | en-GB |
| Нидерланды | nl-NL | en-GB |
| Бельгия | en-GB | fr-FR, nl-NL |
| Люксембург | en-GB | fr-FR, de-DE |
| Россия | ru | uk |
| Украина | en-GB | uk, ru |
| Япония | ja | en-US |
| Корея | ko | en-GB |
| Китай | zh-Hans | en-GB |

**Практические следствия**

- **English (U.K.) — это глобальное английское поле, а не британское.** Индексируется в Великобритании, Австралии, Новой Зеландии, Франции, Германии, Италии, Испании, Нидерландах, Украине и десятке других стран. Если сама Великобритания слабый рынок, поле всё равно остаётся самым ценным английским активом — затачивай его под то, что печатает вся Европа.
- **Вторичная локаль как контейнер под чужой язык.** Локаль, индексируемая в нужной стране, можно залить словами того языка, на котором там на самом деле ищут. Классический приём: арабская локаль, заполненная английскими словами, работает дополнительными 100 символами для США. Так же можно использовать de-DE или it-IT под английские ключи, если в стране ищут по-английски.
- **es-MX выгоднее es-ES:** покрывает Мексику, всю испаноязычную Латинскую Америку и вдобавок индексируется в США.
- **pt-BR выгоднее pt-PT:** Бразилия крупный рынок и тоже даёт слот в США; Португалия маленькая и с высоким уровнем английского.
- **Заполнение fr-CA отключает fallback fr-FR в Канаде.** То же правило действует для любой пары «региональный вариант / основной язык».

## ID сторов для автосаджеста

Заголовок запроса: `X-Apple-Store-Front: <ID>-1,29`

**Проверены на практике:**

| Стор | ID |
| --- | --- |
| США | 143441 |
| Франция | 143442 |
| Германия | 143443 |
| Великобритания | 143444 |
| Канада | 143455 |
| Австралия | 143460 |
| Италия | 143450 |
| Россия | 143469 |
| Украина | 143492 |
| Япония | 143462 |
| Испания | 143454 |

**Не проверены, сверять перед использованием** (пустой ответ бывает и от лимитов, и от неверного ID — отличить можно, запросив заведомо популярный префикс вроде `what`): Мексика 143468, Бразилия 143503, Новая Зеландия 143461, Корея 143466, Нидерланды 143452, Польша 143478, Турция 143480, Индия 143467.

Скрипт `store-query.sh suggest` знает эту карту сам — ему достаточно кода страны (us, jp…); непроверенный ID он пометит предупреждением.

## Лимиты полей

| Поле | Лимит |
| --- | --- |
| Name | 30 |
| Subtitle | 30 |
| Keywords | 100, через запятую без пробелов |
| Promotional Text | 170, не индексируется, меняется без ревью |
| Description | 4000, первые ~170 символов видны до «ещё» |
